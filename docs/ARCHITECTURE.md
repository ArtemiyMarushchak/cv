# Архитектура CV

- `index.html` — готовая страница, которую сразу публикует GitHub Pages.
- `assets/css` и `assets/js` — подключаемые файлы опубликованной версии.
- `src/blocks` — исходники, разложенные по автономным блокам.
- `src/core` — общее ядро и 12-колоночная сетка.
- `src/data/dictionary.js` — единственный словарь переводов RU / SK / EN.
- `public` — favicon, manifest и robots.txt.

Текущие стили сохранены единым файлом `resume.css`, чтобы не изменить утверждённый дизайн. Разделять CSS по блокам лучше постепенно, после визуальной проверки каждого переноса.
