# CV — Artemiy Marushchak

Готовое многоязычное резюме на HTML, CSS и JavaScript.

## Быстрый запуск

Откройте `index.html` или запустите локальный сервер:

```bash
python3 -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## GitHub Pages

Для репозитория `cv` в GitHub откройте:

`Settings → Pages → Deploy from a branch → main → / (root)`

Сайт будет доступен по адресу:

`https://ArtemiyMarushchak.github.io/cv/`

## Главное

- Утверждённая верстка сохранена.
- Мобильные переключатели находятся внутри hero.
- Словарь RU / SK / EN подключён отдельно.
- 12-колоночная сетка находится в `assets/css/grid.css` и `src/core/css/grid.css`.
- Калькулятор и квиз подготовлены отдельными папками для переноса кода из T123.
